# Photo uploads

Upload your LEGO photos into the matching category folder here (jpg/png/webp
are all fine, any file name):

- `fifa/` — פיפא
- `cars/` — מכוניות
- `nike/` — נייק
- `formula/` — פורמולה
- `cities/` — ערים במדינות
- `minifigures/` — דמויות לגו

Adding a new category later? Create a new folder here with any name and
mention it — no fixed structure required.

These are raw uploads, not the live site. Once photos are here, tell Claude
which category is ready and they'll get resized and wired into the actual
site at `assets/images/`.
